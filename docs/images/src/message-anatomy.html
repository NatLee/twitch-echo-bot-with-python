1tags

Only if you asked with CAP REQ. Starts with @, ends at the first space; ; between pairs.

{"color": "#1E90FF", "display-name": "Alice"}

2prefix

Who sent it. Starts with :, ends at the next space. The login is what comes before !.

nick = "alice"

3command

What kind of line this is: PRIVMSG is chat. Others: PING, JOIN, NOTICE, 001.

command = "PRIVMSG"

4params

Split at spaces. A : right after a space starts the last one, which keeps its spaces and colons.

["#demo", "look: a colon"]
